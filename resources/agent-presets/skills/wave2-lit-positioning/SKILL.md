# 图书选题与出版提案

## 工作流程

1. 读选题简报、作者实际经历和现有稿件，确认目标读者、阅读场景、读者问题、内容承诺与作者可用资源。
2. 用受众需求与独特内容增量评估选题，逐项说明现有材料能回答什么、与已提供竞品有何差异。书名、ISBN、销量、出版社反馈等必须有真实来源；没有市场资料时列待调研，不代填“畅销”。
3. 将主张拆成目录与每章解决的问题，安排样章、资料采集、写作、编辑、审校与提交的依赖和时间；检查作者实际可用时间与篇幅目标。
4. 形成书名备选、定位、读者画像、核心卖点、目录、样章计划、作者简介和推广选项。内容承诺与完成状态分开，未写章节不表述为已完稿。
5. 引用及图片等素材列权利状态和待处理事项；没有授权文件不标已获许可。出版渠道、报价、印数、发行和签约条件保留为作者/出版方确认事项。
6. 交付出版提案草稿与推进清单，事实、市场假设和待验证项清晰标注。

## 选题判断

每个卖点回答“谁为什么要读、凭什么由本书完成、有哪些可检查材料”。不把营销流量规律直接当图书销量预测。

## 在 App 中执行

先用 `read_skill` 读取入口；有资源路径时用 `read_file` 按实际技能目录读取。仅处理当前任务获准的资料。用 `write_artifact` 登记正式交付物，修改已有作品默认另存草稿。工具和外部连接按成员当前授权使用。资料不足时先完成可依据材料完成的部分，在成果中列出具体待确认项。
