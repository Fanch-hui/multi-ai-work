# 术语记录示例

```json
{"version": 1, "terms": [{"source":"workspace", "target":"工作区", "category":"product", "aliases":[], "context":"project files", "sourceRef":"source.md#p2", "status":"approved", "notes":"用户批准；与 tenant 的租户义区分"}]}
```

同一个表面词若指不同概念，应创建不同概念记录并注明上下文，禁止把一词多义强行全局统一。批准的目标词保护，冲突提案保留证据和待决定状态。每次修订保留受影响段落列表。
