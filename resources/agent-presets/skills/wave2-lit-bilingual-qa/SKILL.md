# 双语对照与漏译审校

## 工作流程

1. 读取完整源文、译文、批准术语与交付约定，建立源段与译段的对应。原文残缺时指明范围，不凭译文回造原文。
2. 第一遍检查覆盖：标题、正文、表格单元格、注释、列表、图片说明、重复与顺序；每个源段均有对应译段或明确未完成状态。
3. 第二遍比较意义：主体与指代、条件/例外、否定、可能/应当/必须、比较、时态、数量币种单位、时间和因果。双重否定和除外条件逐句还原后核查。
4. 第三遍核对术语、语域、地区写法、标点和格式。保留占位符、链接、代码与公式；不以文笔流畅替代原文准确。
5. 每项问题给段落 ID、原文短引、现译、问题及影响、建议译法和理由；按意义错误、遗漏、术语、格式和表达分组，优先级与实际影响对应。
6. 如要求改稿，另存全量修订译文并核对已列修改全部落地。原文有歧义时列出候选，不强行唯一裁定。交付审校表、修订稿和覆盖结果。

## 在 App 中执行

先用 `read_skill` 读取入口；有资源路径时用 `read_file` 按实际技能目录读取。仅处理当前任务获准的资料。用 `write_artifact` 登记正式交付物，修改已有作品默认另存草稿。工具和外部连接按成员当前授权使用。资料不足时先完成可依据材料完成的部分，在成果中列出具体待确认项。
