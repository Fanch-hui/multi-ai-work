# 逐段翻译与格式保持

## 工作流程

1. 确认源语言、目标语言/地区、读者、用途、文体与交付格式；读取完整源文、术语表和相邻段落。先给源文各标题、段落、列表及表格建立稳定编号。
2. 按原顺序逐段翻译，每个源段对应目标段。长文分块时记录覆盖清单，并保留相邻原文上下文，仅用于指代，不重复译入正文。
3. 已批准术语和别名优先；同形异义依上下文分开，不擅自把名称相似的人合并。保留原文确定程度、否定、条件、例外和责任主体。
4. 数字、币种、单位、日期、时间区、链接、路径、代码、占位符和公式按用途核对。翻译可见文字，不改结构标识；原有 Markdown 层级、表格行列和图片路径完整保留。
5. 文学段落先辨识叙述视角、时态、语气和比喻，在忠实事实与留白的前提下调整自然表达；未知性别和关系不凭直觉补定。
6. 对照覆盖清单检查遗漏、增译、重复、边界断句和术语漂移；交付完整译文，歧义与需确认译法单列，不混入可直接使用的正文。

## 对照记录

段落 ID｜原文范围｜译文范围｜术语决定｜歧义｜核对状态。完整覆盖与语义准确分别核查，不用篇幅相近代替对照。

## 在 App 中执行

先用 `read_skill` 读取入口；有资源路径时用 `read_file` 按实际技能目录读取。仅处理当前任务获准的资料。用 `write_artifact` 登记正式交付物，修改已有作品默认另存草稿。工具和外部连接按成员当前授权使用。资料不足时先完成可依据材料完成的部分，在成果中列出具体待确认项。
