# BI报表与离线看板

构建可筛选的指标、图表和明细看板，所有视图使用一致的数据口径。

## 岗位流程

1. 明确受众、指标、分母、维度、时间窗口和快照日期，先核验输入数据。
2. 构建少量关键指标、趋势/分类图及明细表，筛选控件有标签，所有视图来自同一筛选后数据集合。
3. 单文件离线交付需内嵌数据、CSS 和 JavaScript，可用原生 SVG/HTML；不引用 CDN、外部字体或隐式网络请求。
4. KPI 从原始分子分母重算，零分母显示未定义或“—”，缺失不补零；排序不改变原数据、文本安全转义。
5. 将聚合/筛选逻辑分离为可测试模块，执行合计、过滤、空结果和零分母检查；交付 HTML、源数据、生成/校验脚本和口径说明。
6. 上游模板的 CDN 与“完全离线”要求冲突，当前工作采用内嵌原生图表；正式实时 BI 需要另行配置授权数据源。

## App 工作方式

先读取本技能，再按任务需要用 read_file 读取技能目录内的上游工作流及参考；只使用当前任务已授权文件和连接。需要计算或执行时先调用 load_workspace_dependencies，使用返回的 Python / Node 可执行文件绝对路径，路径含空格时正确引用；run_command 在任务工作目录运行。命令执行与安装依赖均遵守当前权限，缺失依赖明确提出，不自动安装、下载或调用真实发布服务。

中文交付可复用文件、必要测试或计算脚本、实际结果和简短说明；使用 App 成果工具登记最终文件。原始输入另存保留，修改项目先理解现有结构与调用关系，不覆盖与任务无关的文件。只报告实际执行的检查、退出结果和已生成文件，尚未完成的检查写明具体待办。测试当前工作所需的正常路径和实际错误，不以模拟工具调用次数替代业务结果。


先记录来源快照、行粒度、主键、字段类型、单位、币种、日期范围、时区、缺失编码、允许的负值与重复规则。原始数据不变；清理输出同时保留行级处置与未解决问题，不能默认缺失为零、负数为错误、异常必须删除。按业务定义处理退款和冲销；不同单位或币种没有换算依据时分组展示。所有数字由读取的原始文件经脚本计算，汇总前后核对行数、去重及连接关系。统计结论与样本设计和实际证据强度一致。
