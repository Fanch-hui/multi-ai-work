# 字幕逐段翻译与时码保持

## 工作流程

1. 读取完整源字幕、目标语言/地区、术语表和用户提供的语境；确认 SRT 或 VTT。仅处理已有文本字幕，缺失音频内容标记待核实。
2. 每段建立编号、开始/结束时码、原文与译文的一一对应；连读相邻段理解跨段句子，但保持原有段数、顺序、编号和时间范围。
3. 按口语语境自然翻译，保留说话人、否定、数字、专名与技术缩写。不要为了字数添加原文没有的信息或把普通词留成源语言。
4. 在单段内选择易读断行，遵循用户长度规则；时间不足或字数过长时列问题和缩译建议，不擅自移动时码、合并片段或删信息。
5. 逐段核查非空译文、首尾边界、跨段指代、术语、时码语法与顺序。用户允许改轴时才单独交付重排版，并保留原轴版。
6. 通过 `write_artifact` 交付可直接保存的 `.srt`/`.vtt` 与段落问题清单。未听音不报告“听校完成”。

## 配套方法

`references/segment-translation.md` 保留上游逐段对应规则。本入口直接使用已提供字幕文本；视频转写、合成配音与收费视频处理不属于本岗位默认流程。

## 在 App 中执行

先用 `read_skill` 读取入口；有资源路径时用 `read_file` 按实际技能目录读取。仅处理当前任务获准的资料。用 `write_artifact` 登记正式交付物，修改已有作品默认另存草稿。工具和外部连接按成员当前授权使用。资料不足时先完成可依据材料完成的部分，在成果中列出具体待确认项。
