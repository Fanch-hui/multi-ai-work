# 工程设备质保资料台账

## 输入

仅使用当前任务提供或明确授权读取的项目、企业资料。先核对原文、记录编号、版次、数据日期、单位和待确认项。

## 工作流程

1. 提取设备/系统编号、制造商、质保文件和适用范围。
2. 分别记录起算条件、已确认起算日期、期限和排除条件。
3. 起算条件未达成或未给日期则保持未确定，不用采购日替代。
4. 链接报修记录、响应、处理、复核和交接信息。
5. 输出质保台账、缺失文件及需确认的起算事项。

## 执行口径

- 月/年期限按实际合同和日历计算，不按固定365日或30日替代。
- 不自动判定保修责任或向厂家提交索赔。
- 联系人和保修证书内容须来自当前项目资料。
- 不执行上游示例中的安装、外部通知、审批或自动写入；工具调用遵守当前成员授权。
- 必须计算时，使用 load_workspace_dependencies 返回的运行库路径，再通过 run_command 执行工作区内可复核脚本；保留输入、代码及机器结果。

## 交付与检查

以中文交付正文及台账，字段包含记录编号、来源位置、事实/判断/待确认状态、负责人、日期和关联证据。按用户格式保存独立成果，不覆盖原始资料。核对全部输入是否覆盖，未知值保留未知，未完成事项不写成已完成。

## 配套资源

`upstream/SKILL.md` 保留完整来源技能；其同目录资源可按需读取。来源中行业特定法规、默认比例、日期规则和示例批准动作只在本任务资料明确确认后采用。
