# 成本与贡献分析

来源：改编自固定版本 `anthropics/financial-services` 的 unit-economics 中 Margin Waterfall 与 fully loaded unit economics 方法，保留收入、成本和利润逐层勾稽思路。以下成本对象、分摊、差异桥接与管理口径流程由 multi-AI work 新增。固定提交、原路径与许可证见 `NOTICE`。

## 执行与资料

- 通过 App 当前已授权工具读取用户提供的成本表、业务数量和口径；保留文件、表页或行号来源。配套资源通过 `read_skill` 的 resource 参数读取，路径相对此技能目录。
- 使用中文，区分实数、用户假设与缺项。先完成已有资料支持的测算；仅对会改变结果的缺失口径提问。币种、期间、税务及会计分类沿用企业指定口径。
- 数值计算先用 `load_workspace_dependencies` 取得运行库路径，再通过已授权的 `run_command` 实际执行。脚本直接读取源资料，保存输入映射、计算脚本及结果文件，读取结果后撰写报告；Office 文件使用 App 配套技能。命令或运行库缺失时交付口径、公式及待算项，标明尚待执行的计算。
- 原始资料保留，结果另存到获准工作目录并登记成果。外部连接、账务和审批操作依实际授权执行。

## 1. 建立成本口径

先写计算脚本读取实际源文件，提取数值及来源位置；输入映射保留源文本和解析字段，避免手抄常量脱离原文件。再确定成本对象（产品、订单、项目、服务或部门）、分析期间、币种及数量单位，区分生产量、销量和工时。只有口径一致的数量与成本才可相除或相加。

为每项输入记录金额、单位、来源和分类：

| 字段 | 处理要求 |
| --- | --- |
| 数量与收入 | 数量 Q、单价 P、收入 R；标明含税/不含税及折扣；用实际收入核对 P×Q |
| 直接成本 | 能直接归属对象的材料、人工等；注明是单位金额还是期间总额 |
| 成本性态 | 独立判断固定、变动及混合成本；直接成本也可能固定，间接成本也可能变动 |
| 分摊费用 | 成本池、覆盖对象、驱动数量、分配规则及已分摊金额 |
| 口径调整 | 一次性费用、库存变动、计提等按资料单列，并说明影响的指标 |

混合成本只有资料支持拆分时才拆为固定与变动部分。已明确的管理分类先按指定口径给出数值，会计分类待确认项附在对应行。

## 2. 并列计算管理指标

在单一对象、当期数量 Q 与成本对应时，设单位直接成本为 d，全部单位变动成本为 v，当期固定费用为 F：

- 单位直接成本 d = 各单位直接成本之和；直接成本口径单位毛利 = P − d，总毛利 = R − 对应直接成本总额。
- 单位贡献 = P − v；总贡献 = R − 变动成本总额。在 R=P×Q、变动成本总额=v×Q 时，总贡献=(P−v)×Q。
- 经营利润 = 总贡献 − F。固定费用只扣一次；直接成本已含在变动或固定费用中时，不能再在利润中重复扣除。
- 用户指定固定费用全额按销量分摊时，单位完全成本 = v + F/Q，单位完全成本利润 = P − v − F/Q；其乘 Q 应回到经营利润。
- 其他分摊规则按用户指定驱动执行，明确完全成本包含的费用范围。多对象利润合计后，仅再扣未分配费用。

贡献扣变动成本，直接成本口径毛利扣指定直接成本；分别显示名称、成本范围、单位金额与总额。制造成本口径涉及生产量、产销存或产能分摊时，按已有台账衔接，销售贡献与产品成本分别核对。

Q=0 时，用期间总额除以 Q 得到的单位成本、单位利润与分摊率标为“未定义”；若资料独立给定单价 P 和单位变动成本 v，P−v 仍可作为单件贡献参数，不能因当期销量为零将其清空。保留期间总成本和利润；无销售收入、无变动成本时经营利润为 −F。多对象中零数量对象按既定规则处理，其未分摊成本单列。

## 3. 核对分摊和总额

- 每个成本池先确定费用总额和分摊驱动。分摊额=成本池×对象驱动量/合计驱动量；驱动合计为零时单列待分配金额。
- 原始成本只进入一个成本池；直接归属的费用从待分摊池剔除。对象分摊额合计加未分配额应等于成本池总额。
- 用单位金额×对应数量核对总额，用收入−全部变动费用−固定费用核对利润。差额追到来源、数量口径或舍入；计算保留精度、展示末端舍入。
- 库存、在制品或范围差异导致管理成本与账面费用不同的，列明调整桥接及未解释差额。

## 4. 解释差异与给定情景

两期或预算对实际先统一对象、期间长度和数量单位。单一对象且总成本 TC=Q×v+F 时，按以下固定顺序做精确桥接（0 为基期，1 为本期）：

- 数量影响=(Q1−Q0)×v0；单位变动成本影响=Q1×(v1−v0)；固定费用影响=F1−F0。三项相加等于 TC1−TC0。
- 利润桥接：数量影响=(Q1−Q0)×(P0−v0)，价格影响=Q1×(P1−P0)，单位变动成本影响=−Q1×(v1−v0)，固定费用影响=−(F1−F0)。合计等于两期经营利润差。
- 有对象组合变化时逐对象计算后汇总，并说明数量项包含组合影响。进一步拆成总量与组合时明确替换顺序；新增或退出对象缺乏基期单位值时单列其净变化。
- 某期数量为零且未提供单位价格/成本时，不从零总额反推单位值；保留可算项目并单列未拆解差额。
- 仅在任务要求情景测算时使用用户给定的价格、数量、材料单价、人工效率或费用情景；未提供幅度时给驱动关系和待选参数，不自选增长比例或新销量。说明产能、阶梯费用与供应合同等已有约束，逐情景重算贡献和利润。

降本建议按可控驱动落到具体费用项，给出预期金额、适用数量、一次性投入和资料依据；将固定分摊率下降与实际费用节约分别说明。

## 交付

按任务所需交付口径及来源表、单位与总额指标表、分摊核对、成本/利润差异桥接和给定情景结果。结论优先说明成本主要来自哪里、哪些因素改变利润、建议动作及所需条件；附可复算公式与尚待补齐的数据。
