# 图表设计与可复现输出

根据比较、趋势与分布选择图表，核对尺度、单位和原始数据。

## 岗位流程

1. 明确读者问题与数据关系，先从文件计算绘图表，保留数据来源、单位和日期。
2. 比较用条形图，趋势用折线，分布用直方图或原始点；退款/亏损等负值使用带零线的适当图。
3. 条形从零开始，跨图比较尺度一致；轴、图例、直接标签和不确定性完整，避免三维和误导双轴。
4. 用现有绘图库；独立小样可用 Python 标准库生成 SVG/HTML，文本必须转义，附可读数据表和替代说明。
5. 输出图、绘图数据和生成脚本，核对实际图中数值与报告一致；浏览器交互视觉效果由用户确认。
