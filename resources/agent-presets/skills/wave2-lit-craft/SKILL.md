# 叙事写作与场景修改

## 工作流程

1. 读取本场简报、前后文、人物状态和文风示例，确认这次是新写、修改、桥段还是润色；选择最小适用范围。
2. 写出场景开始状态和结束变化。用人物行动、选择和对话承载压力，细节由当前视角的观察决定；限定视角不写他人未公开的内心。
3. 对话兼顾人物差异、关系和信息变化，保留潜台词；过渡只承载必要时间地点变化，不扩出未经要求的情节。
4. 先完成场景，再检查因果、空间、知识状态、语气和节奏。保留作者有意的含混与句式，不机械加戏、煽情或统一短句。
5. 交付可直接阅读的正文；创作决策、疑问和建议新增设定单列。核对禁改项，未获确认的提案不写回作品设定表。

## 配套方法

场景与对话读取 `resources/scene-construction.md`，视角与叙事距离读取 `resources/prose-writing.md`，文风读取 `resources/style-analysis.md`。题材参考只按当前需要读取 `resources/genre/`。

## 在 App 中执行

先用 `read_skill` 读取入口；有资源路径时用 `read_file` 按实际技能目录读取。仅处理当前任务获准的资料。用 `write_artifact` 登记正式交付物，修改已有作品默认另存草稿。工具和外部连接按成员当前授权使用。资料不足时先完成可依据材料完成的部分，在成果中列出具体待确认项。
