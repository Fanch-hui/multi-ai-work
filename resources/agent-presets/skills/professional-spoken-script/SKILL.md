# 口播脚本编辑

把用户资料整理成听一次就能理解、朗读顺畅、时长可核对的稿件。用户指定的语言、时长、风格、原文保留范围和交付格式优先。

## 工作输入与资料

- 从任务和已提供资料提取听众、听众已有知识、使用场景、讲述者身份、核心目的、目标时长及语言。只追问影响核心内容的缺项；其余可采用明确说明的假设起草。
- 明确听众听完应理解、记住或采取什么行动。讲解、故事、新闻、课程和商业介绍分别选择合适的展开方式；行动引导只在任务需要时加入。
- 通过 App 已授权的文件、附件或外部资料工具读取资料，区分已核对事实、用户观点、创作内容与待确认信息。数字、引语、案例和因果判断须能追溯到资料；缺证据的关键陈述先标为待确认或调整措辞。
- 本技能配套文件通过 `read_skill` 的 resource 参数按技能根目录读取。文本交付使用现有文件和成果工具；另存至当前任务目录并登记成果，保留源资料。

## 组织和口语化

1. 先确定一条主线和必要信息，再安排开场、主体和收束。开场尽早交代与听众有关的问题或场景；收束回应主线。信息顺序按理解需要组织，结构长度随内容和时长调整。
2. 每段围绕一个信息点，先给可理解的结论或情境，再用必要解释和具体例子支撑。专业名词首次出现时补一句通俗释义，省略听众已经掌握的解释。
3. 长句拆成自然短句，一句承载一个主要动作或判断。把书面连接词、名词堆叠和多层定语改成日常说法；保留事实边界、必要条件和原意。
4. 转场直接说清信息关系，例如“原因有两个”“再看它怎么发生”“这里最容易混淆的是”。指代对象要明确，听众无需回看文字也能跟上。
5. 用朗读视角检查拗口、换气点、连续同音词和重复信息。删改时优先保留核心信息、证据及必要解释，按用户要求保留口头风格。

## 数字、专名与录制标记

- 将需要口述的年份、日期、百分比、金额、单位、区间和公式转换为明确读法。读法依语境选择，例如年份逐位读、数量按数值读；口语取整须保留原始值与取整说明。
- 缩写、外语、人名、地名和产品名首次出现时确认读法。用户给定读法优先；无法确认的专名在录制备注中标为“读音待确认”，不凭空填写。
- 按需要提供轻量标记：`/` 为短停顿，`//` 为段落停顿，`【重读：词语】` 为重点，`[语气：平静]` 为局部提示。只标影响理解和节奏的位置，避免逐词标注。
- 录制提示与实际要读的正文分开。读音说明、资料来源、时长说明和编辑备注均不计入朗读正文；确需读出的词写入正文。

## 时长估算与核对

- 精确控制时，将最终口述纯文本另存为 UTF-8 文件，先用 `load_workspace_dependencies` 找到 Python，再通过 App 授权的 `run_command` 执行 `scripts/measure_timing.py`。指定 `--mode zh` 或 `--mode en`、`--rate`（每分钟字/词数）和 `--pauses`（整稿额外停顿秒数），可选 `--target-seconds` 与 `--marked`；读取 JSON 输出后据此说明段落数、总字/词数和估算时长。工具不可用时只提供粗估，不宣称精确计数。
- 脚本按空行分段。中文统计非空白、非标点字符，英文按词统计；数字、缩写等先在正文展开为实际读法，或明确标出读法。估算时长为总字/词数 ÷ 每分钟语速 × 60 + 整稿停顿预算。若所用语速已包含停顿，将 `--pauses 0`，避免重复计算。脚本结果是文字估算，不是实测语音时长。
- 以最终纯文本作为计时依据。可另给含录制标记的 `--marked` 文件核对：脚本去除 `/`、`//` 和 `[语气：...]`，并保留 `【重读：词语】` 中的词；口述内容不一致时明确报错，修订稿件后重新运行。
- 尚无语速时，可暂按中文每分钟 220 字或英文每分钟 140 词估算，并明确这是可调整的编辑假设。混合语言分别计量后相加，避免直接把所有字符当作同一种单位。
- 整稿估算秒数 = 总字/词数 ÷ 每分钟语速 × 60 + 全稿额外停顿预算。段落逐项报告计数，正文时长、停顿预算和总估算分别列出；若用户提供的是包含停顿的整体平均语速，将额外停顿设为零。
- 用户要求硬时限时，将目标总时长分配到各段并相应压缩正文。
- 超时时先删旁枝、重复和不影响理解的例子，再检查句式。低于目标时补充必要解释或例证，避免用空泛铺垫补时长；每次改稿后重新运行脚本。
- 只有实际录音或试读计时才标为“实测”；脚本计算标为“估算”。获得实测后按真实停顿和易卡顿段落修订，给出修订后的总时长依据。

## 交付前检查

先交付可直接使用的稿件。需要录制时附轻量标记版；需要时长控制时附段落时长表和总时长，并集中说明语速与计数口径。用户只要正文时，按其格式交付。

核对主线是否完整、事实和引语是否准确、语气是否符合场景、数字和专名是否能顺畅读出、各段转场是否明确，以及段落时长相加是否吻合整稿。将资料来源和待确认项放在正文之外。
