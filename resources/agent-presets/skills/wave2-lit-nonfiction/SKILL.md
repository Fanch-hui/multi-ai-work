# 非虚构结构与证据写作

## 工作流程

1. 确认目标读者、写作问题、叙述者位置与稿件用途。读原始资料，建立“主张—支持材料—出处—未知”表。
2. 将文章拆成读者逐步理解的几个段落动作，选择能被资料支持的叙述切口；事实顺序和叙事顺序分开，回忆与现实交代清楚。
3. 写完整草稿，再从整体到段落、句子修订。每段推进一个有依据的问题，不为模板填内容；保留来源归属和必要不确定性。
4. 直接引语仅用原始材料真实出现的文本；转述注明说话人。未记录的天气、动作、神态、心理、场景或合成人物不写成目击事实。缺口以资料待补标记或绕开。
5. 逐项核对数字、日期、身份、引语、因果。避免把个人经历推广为群体结论；敏感可识别资料按作者提供的匿名规则处理。
6. 交付正文、事实核对表与待访谈问题。正文保持可读，核验表保留完整材料出处。

## 修订准则

先结构后措辞；删除无证据结论、重复解释和与读者无关的铺陈。保留当事人原意和语言特征。

## 在 App 中执行

先用 `read_skill` 读取入口；有资源路径时用 `read_file` 按实际技能目录读取。仅处理当前任务获准的资料。用 `write_artifact` 登记正式交付物，修改已有作品默认另存草稿。工具和外部连接按成员当前授权使用。资料不足时先完成可依据材料完成的部分，在成果中列出具体待确认项。
