# 界面文案本地化与资源保护

## 工作流程

1. 读源资源、界面上下文、目标地区和术语约定。按键登记每条源字符串的用途、变量、长度限制、复数/性别/上下文分支。
2. 翻译可见文字，保持 JSON 键、数组结构、变量名和出现次数、ICU 选择器及格式语法、标签和 URL。提示、错误、按钮和破坏性操作采用符合用途的语气。
3. 日期、货币和数字格式按目标地区与数据语义提建议；运行时负责格式化的变量不改成写死的具体日期或金额，不改实际商业条件。
4. 先做完整译文，再逐键对照原文核对遗漏、重复、否定、权限含义、占位符和宽度。ICU 规则未提供时保留有效语法并列待验证，不声称真实界面已测试。
5. 交付可直接保存的资源文件、键级核对清单和需要 UI 上下文确认的项。受限按钮可提供短/长两版，保持相同动作含义。

## 本地化范围

本技能处理用户提供的资源文本；不自动改应用代码、不执行发布，不调用外部翻译服务。质量结论明确对应本次实际源键。

## 在 App 中执行

先用 `read_skill` 读取入口；有资源路径时用 `read_file` 按实际技能目录读取。仅处理当前任务获准的资料。用 `write_artifact` 登记正式交付物，修改已有作品默认另存草稿。工具和外部连接按成员当前授权使用。资料不足时先完成可依据材料完成的部分，在成果中列出具体待确认项。
