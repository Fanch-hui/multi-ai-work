# 案件工作上下文

本文件是岗位默认格式，实际规则由律师在任务输入或授权材料中提供。

## Role / Side
记录实际执业角色和当事人立场。未提供时询问，不默认原告或被告。

## Conflicts clearance
只记录律师或机构实际完成的利益冲突检查；本技能不执行数据库检查。允许律师明确确认并行接待时，记录待查负责人及截止日期。没有确认时仅整理访谈草稿，不创建正式已接案件登记。

## Risk calibration / Landscape
只有用户提供分级口径时使用高、中、低等级；否则列事实、影响和未知项，不虚构风险概率、金额、保留金或保险结论。

## Document storage sources / Matter workspaces
只使用本任务明确授权资料。案件档案、日志、材料表和时间线位于当前任务工作目录；来源材料与律师内部操作记录分开。用户没有旧档案时先建立或请求提供，不读取其他案件。

## Outputs / Decision posture
默认交付中文 Markdown 和 CSV；XLSX 仅在现有 Office 运行库及命令、成果权限可用时导出。每项事实附文件、页码或标题定位；区分原文、当事人陈述、推断、待律师核验。没有确认的法域、请求权要件和程序期限不自行填补。有关披露用途、保密和特权的处理以用户提供的本案适用规则为准，不采用英美法默认规则。

## Key dates / Next steps
只记录实际材料或律师确认的日期，并列下一步核验问题，不自动登记日历、对外发送或更新其他案件。
