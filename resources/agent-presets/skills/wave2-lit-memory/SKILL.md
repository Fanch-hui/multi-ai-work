# 连载设定与伏笔连续性

## 工作流程

1. 将作者确认的设定表与已写正文分别读取并标记版本、章号。提取人物年龄、所在地、能力、关系、物品、知道的信息与世界规则。
2. 逐章记录真实发生的状态变化，引用章段，不把人物猜测、传闻、梦境、假设升级为既定事实；区分作者知道、读者知道和人物知道。
3. 建立时间线和伏笔表：引入位置、表层信息、待回答问题、状态、已发生回收。未回收并非必然错误，按已承诺时间与影响排序。
4. 发现冲突时并列原设定与新正文、出处和具体后果，提出最小修订选项；作者尚未裁决前保留原记录与问题，不自行更改正史。
5. 交付增量设定表、连续性问题清单和下一章上下文卡。卡片只含当前写作必需的已定状态与开放问题，避免把全书无差别复制。

## 配套方法

读取 `resources/fact-extraction.md` 的状态差异提取法；上下文与问题管理分别见 `resources/story-context.md`、`resources/writing-issues.md`。本地作品资料是工作文件，App 长期记忆仍遵循成员授权。

## 在 App 中执行

先用 `read_skill` 读取入口；有资源路径时用 `read_file` 按实际技能目录读取。仅处理当前任务获准的资料。用 `write_artifact` 登记正式交付物，修改已有作品默认另存草稿。工具和外部连接按成员当前授权使用。资料不足时先完成可依据材料完成的部分，在成果中列出具体待确认项。
