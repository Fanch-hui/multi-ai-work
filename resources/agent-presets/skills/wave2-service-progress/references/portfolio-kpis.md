# 项目进度指标口径

所有指标先确定状态日、批准版本、范围、分母和完成定义。缺数据保留未知，不以0替代。

| 指标 | 可采用公式 | 核对事项 |
|---|---|---|
| 验收完成比例 | 已验收交付物权重/批准交付物总权重 | 权重需批准；开发完成和待验证分开 |
| 工作量完成比例 | 同口径已完成工作量/批准工作量 | 剩余估算变化需单独解释 |
| 偏差天数 | 当前预测完成日与原基线日期之差 | 工作日/自然日统一、记录日历 |
| 预计总成本 | 已发生+未计入已发生的已承诺成本+其他剩余预测 | 分项不重叠，现金支付与费用确认口径明确 |
| 预算偏差 | (预计总成本-批准预算)/批准预算 | 预算0时不求百分比，保留金额 |
| 人员容量利用率 | 同期已分配工时/同期净可用工时 | 会议/沟通/审核计入；净容量不重复扣减 |
| 阻塞时间 | 有完整开始/结束记录的阻塞时长 | 未结束阻塞以状态日结算并标为进行中 |

阈值和红黄绿状态使用项目实际标准。没有可比样本时先做事实偏差和条件预测，不生成统计置信度或保证日期。
