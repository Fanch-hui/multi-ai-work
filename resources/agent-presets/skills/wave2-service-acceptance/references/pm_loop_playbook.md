# 项目交付核查流程

1. **明确基线**：读取实际批准的SOW、需求、验收标准和变更版本，记录状态日。
2. **收集证据**：整理任务、交付文件、测试记录、缺陷、会议与批准记录；先核对版本和范围。
3. **逐项核验**：按验收矩阵检查，不把空白补为通过；实际命令核验时保存命令与输出，人工验证保存真实记录。
4. **记录问题**：区分阻塞缺陷、非阻塞遗留项、资料缺失、未批准范围和待决定事项，记录真实责任人。
5. **安排整改**：列处理动作、前提、预计工作量与可用资源；日期和批准状态来自实际输入。
6. **复核与交接**：整改后对应新证据，复核文档、培训、运维、支持联系人与遗留项接收。
7. **请求决定**：准备可审阅结论草稿，由既定有权人决定通过、附条件通过、豁免或延期；保留实际签署记录。

本流程可使用用户提供的文件及获准系统导出；不依赖其他仓库、外部脚本、模型子代理或特定项目系统。
