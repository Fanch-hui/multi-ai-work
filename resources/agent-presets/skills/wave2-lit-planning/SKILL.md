# 小说结构与章节策划

## 工作流程

1. 读取作者简报和已确定的设定，提取题材、读者体验、视角、篇幅、人物欲望、禁改项；把已确认设定与备选构思分栏。
2. 定义故事的核心问题与主人公选择。列出开端、升级、转折、困境和收束，检查事件之间的原因、阻碍与代价。结构服务作品，不强制套固定幕数。
3. 按章写“时间地点—视角人物—当章目标—阻碍—行动选择—变化—后续期待”，关键揭示与伏笔标注铺垫和回收位置。
4. 核对人物知识边界、行动能力、地理与时间条件，任何新增世界规则或背景都标为创作建议，未定结局保留可选方向。
5. 交付故事简案、人物弧线与章节表，另列作者需要决定的问题。小改动仅处理指定范围。

## 配套方法

结构规划读取 `resources/story-architecture.md`；具体章节读取 `resources/story-architecture/chapter-and-scene.md`；时间矛盾读取 `resources/brainstorming/continuity-timeline.md`。这些文件中的跨技能名称属于方法引用；本入口已包含独立执行流程。

## 在 App 中执行

先用 `read_skill` 读取入口；有资源路径时用 `read_file` 按实际技能目录读取。仅处理当前任务获准的资料。用 `write_artifact` 登记正式交付物，修改已有作品默认另存草稿。工具和外部连接按成员当前授权使用。资料不足时先完成可依据材料完成的部分，在成果中列出具体待确认项。
