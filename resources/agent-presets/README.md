# 职业预设内容

目录包含 24 类职业与人群、175 个具体岗位、296 个独立适配的 Skill 资源目录。161 个岗位配套 3 个 Skill，另外 14 个按职责配套 1～2 个。技能入口保留固定上游工作流程，引用资源、脚本、模板和许可证随包分发；中文岗位指令映射到 App 授权工具和工作目录。

`catalog.json` 是内容清单，`readiness.json` 保存与版本和资源摘要绑定的验收状态。官方打包只选取内容审阅和真实运行验收均通过的岗位；运行完成本身不代表内容合格。

## 技能配置

技能按岗位核心交付选择，辅助技能只在对应输入和任务需要时读取。口播编辑使用口语与时长流程，成本分析使用成本对象与分摊流程；术语管理聚焦术语表，双语审校聚焦原译文核对，质量文控聚焦版本与生效记录。

共用技能保持同一份资源与来源。财务预算与报告、商务与技术翻译有共同的基础方法，由岗位指令明确各自的输入、读取顺序和交付重点。技能数量由职责决定。

## 运行验收

使用 `tests/fixtures/presets` 中的模拟输入，经临时 Core 创建独立成员，实际读取绑定 Skill 并交付文件。审阅实际成果的来源、计算、约束和职责覆盖，失败项修正后重新运行；验收也包含带审阅意见的完整交付修订。详见 [验收运行器](../../scripts/presets/RUNNING.md)。

当前代表性验收环境为 macOS arm64，使用 Qoder 通道的 Qwen3.8-Max / Qwen3.8-Flash，以及 Antigravity 通道的 Gemini 3.8 Flash，各岗位实际通道和模型记录在 `readiness.json`。验收以每岗位的输入与成果为范围，不代表其他模型、平台或所有任务均已验证。法律岗位只使用任务确认的法域、规则与模板，不提供未经核验的中国法律程序判断。需要精确计算、绘图或工时校验的岗位声明命令工具和随包运行库为必需依赖，成员配置时由用户授权。

## 打包与发布

```sh
python3 scripts/presets/build.py --output release/presets
python3 scripts/presets/build.py --output release/presets-release \
  --repository Fanch-hui/multi-ai-work-presets --tag presets-X.Y.Z \
  --acceptance /path/to/acceptance.json
```

资源摘要由排序后的 `[相对路径, 文件 SHA256]` JSON 行计算，与 Core 安装器一致。岗位指令及全部资源必须匹配验收摘要；脚本、模板或引用资源改动后也需重新验收。运行明细与成果单独保存，不随公开技能包分发。

发布到 [官方分发仓库](https://github.com/Fanch-hui/multi-ai-work-presets) 的固定 Release 标签，上传已验收目录引用的 ZIP、`catalog.json`、`catalog-v2.json` 和 `SHA256SUMS`。不修改已经发布的同版本内容，后续内容变更使用新预设版本与新 Release 标签。用户在市场检查更新并手动应用。

扩展分类客户端使用 `catalog-v2.json` 获取完整目录；`catalog.json` 为最初 13 类客户端提供兼容目录。两者指向固定版本并校验摘要。使用 `prepare-release.py` 可在全部岗位验收通过后生成两个目录、许可证完整的资源包和校验清单。

开发与打包版本的默认目录地址由 `resources/market-config.json` 提供，`MULTI_AI_MARKET_CATALOG_URL` 可覆盖。联网刷新只影响目录缓存；安装使用固定标签、摘要校验的 ZIP。

## 来源与许可

每个 Skill 的 `LICENSE` 和 `NOTICE` 以及元数据记录具体来源、40 位提交、原始路径、Star 核验日期和改动说明。所有入选来源仓库核验时至少 200 Star，同时比较岗位覆盖、具体内容质量和热度，匹配与质量相近时优先更高 Star。不同材料分别适用 MIT、Apache-2.0、CC BY-SA 4.0、BSD 或 Matplotlib 许可，详见对应目录；改编材料按各自许可保留必要署名与分发条件。

Skill 资源按原始字节保存，包括二进制与 CRLF 文件，Git 不作文本换行转换，以保持摘要和离线引用完整。
